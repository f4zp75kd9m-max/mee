Басты бет

Қош келдіңіз! Бұл — менің жеке кәсіби веб-парақшам.

Мен туралы

Мені Максатова Зухра деп атайды. Мамандығым — «Цифрлық аналитикалық», қазіргі уақытта Қазақ Ұлттық Қыздар Педагогикалық университетінің 3-курс студентімін.


Бос уақытымда бағдарламалауды және жаңа технологияларды үйренуді ұнатамын. Кәсіби мақсатым — пайдаланушыға ыңғайлы веб-қосымшалар жасайтын frontend-инженер болу.

Менің дағдыларым

Бағдарламалау тілдері мен технологиялар

  • Бағдарламалау тілдері:
    • Python
    • Java
  • Web-технологиялар:
    • HTML
    • CSS
    • JavaScript

Дағдылар деңгейі бойынша

  1. HTML/CSS — орта деңгей
  2. JavaScript — орта деңгей
  3. Python — орта деңгей
  4. Java — бастапқы деңгей
  5. SQL — орта деңгей
  6. Ағылшын тілі — B1 деңгей
  7. Командада жұмыс істей білу
